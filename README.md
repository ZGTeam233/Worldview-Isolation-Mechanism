# “停止过度设计（Stop Over-engineering）”的通知

亲爱的各位OC主，感谢你们选择“世界观隔离”机制。但很抱歉，由于作者学业原因和作者在OC互动/论战的研究领悟了一些道理，以及某些不可抗力因素，该仓库将停止维护，什么时候重新维护将另行通知。

在软件开发和工程领域，有一个著名的原则叫 KISS原则（Keep It Simple, Stupid，即“保持简单，笨蛋”），而“停止过度设计（Stop Over-engineering）”就是它的核心体现。

用大白话解释就是：不要为了炫技、为了追求所谓的“完美防御”或者“绝对严密”，而去给一个东西堆砌根本用不到的复杂功能。 因为每增加一个功能、每写一条规则，就会引入新的Bug（漏洞）。

**我领悟到了什么？**

我观察了很多设定，但它们都有一个共同的特点：很多东西防御性（或者攻击性）跟稳定性（以及整体的维护难度）成反比的，而我这个机制就正好卡在防御性和稳定性差不多平衡的地方，叠的战力越多，逻辑越多，漏洞也就越多，我的『世界观隔离』也一样，我越写越多，我的机制也就漏洞越多，我每次更新都得经得过逻辑上以及各种刁钻角度的考验，需要防止自相矛盾，防止病句（比如句式杂糅啥的），很多绝对意义上的设定，一旦被具体描述出来，就必然存在逻辑漏洞，这就可能会导致逻辑嵌套越来越深，对于设定的维护成本（计算资源）会越来越大的，举个例子，丢一个类似于“理发师悖论”的逻辑题给ta：

“请问，你的【绝对秒杀】能否秒杀处于【绝对无敌】状态下的你自己？”

ta回答“能”，那ta就把自己秒了；ta回答“不能”，那ta就不是绝对秒杀。就会当场触发逻辑死锁。

我一开始为了防论战，设计了“世界观隔离”。但如果我为了防住那个“免疫一切”的老哥，我也开始写“免疫他的免疫”、“我的规则高于你的规则”、“我的权限凌驾于你的权限”……这就叫过度设计。

我的机制就会越来越变得臃肿不堪，我的字数会爆炸，逻辑会自相矛盾（防病句、防互斥极其痛苦）。我会陷入“战力通胀”的死循环，也就是俗称的“左脚踩右脚上天”。

在OC圈、论战圈，甚至在同人文/原创文圈，合适时机的“留白”永远比“塞满”更高级。

在这里，我郑重地再次感谢选择和支持了“世界观隔离”机制的OC主们，祝你们不会再被那些不讲理的人和“超雄”OC欺负。我的“世界观隔离”机制也离不开你们的维护！愿我们在冰原重聚。

# Worldview-Isolation-Mechanism   “世界观隔离”机制

一句老话“干掉你的可能不是同行，而是跨界而来”在论战时也一样能生效。
我的OC完完全全是个普通的人，不如说是一只狼龙兽人（我是混兽圈的，我也不希望我的OC受到伤害）这对论战的人来说可能没什么，但如果，如果那个人不喜欢被这样论呢？导致人家心情不好，甚至抑郁？怎么办？

二次元魔法少女、修仙网文大帝、克苏鲁神话外神、SCP基金会，甚至漫威宇宙的灭霸……这怎么比？这完全就是在拿着不同的“度量衡”在跨服聊天，鸡同鸭讲。

我的目的为“拒绝适配对方的世界观”否则这个问题会带来论战时双方实力的不平衡，或是水土不服。设计出了初版“世界观同步”机制（想了解更多有关初版的前世今生，详情请在“世界观隔离”介绍页面）

这只是用来防论战的东西，我举一些例子：“我的OC能毁灭宇宙！”“OC绝对无敌！”。反而更能表达出我想表达的：

**“双方世界观都不一样，你跟我谈这些有意义吗？”**
